Where do I find the feed link?
Google Calendar
Settings → pick the calendar under “Settings for my calendars” → Integrate calendar → Secret address in iCal format.
Outlook / Microsoft 365
Settings → Calendar → Shared calendars → Publish a calendar → choose the calendar and “Can view all details” → Publish → copy the ICS link.
iCloud
Calendar on Mac → hover the calendar → Share → tick Public Calendar → copy the link. webcal:// links are fine.
