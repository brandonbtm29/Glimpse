One step first

For safety, the settings panel stays locked until an admin password is set on the computer running Glimpse. Open a terminal there, in the Glimpse folder, and run:

.venv\Scripts\glimpse admin-password

On macOS or Linux: .venv/bin/glimpse admin-password. Then reload this page.
